# USE CASE: 6 View Employee Details 

## CHARACTERISTIC INFORMATION

### Goal in Context

As an *HR advisor* I want *to view an employee's details* so that *The employee's promotion request can be supported.*

### Scope

Company.

### Level

Primary task.

### Preconditions

The employee's details exist on the system.

### Success End Condition

The employee's details can be viewed.

### Failed End Condition

The employee's details cannot be accessed.

### Primary Actor

HR Advisor.

### Trigger

A request for an employee's details to be viewed is sent to HR.

## MAIN SUCCESS SCENARIO

1. HR advisor captures details of the employee whose details are to be accessed.
2. HR advisor looks up the details of the employee.
3. HR advisor can use the details to support the employee's promotion request.
