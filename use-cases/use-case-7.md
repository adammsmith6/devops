# USE CASE: 7 Update Employee Details

## CHARACTERISTIC INFORMATION

### Goal in Context

As an *HR advisor* I want *update an employee's details* so that *the employee's details can be kept up-to-date.*

### Scope

Company.

### Level

Primary task.

### Preconditions

The employee's details are in the system and can be accessed.

### Success End Condition

The employee's details can be accessed and updated.

### Failed End Condition

The employee's details are not updated.

### Primary Actor

HR Advisor.

### Trigger

A request for an employee's details to be updated sent to HR.

## MAIN SUCCESS SCENARIO

1. HR advisor captures details of the employee whose details are to be updated.
2. HR advisor accesses the employees details from the system.
3. HR advisor updates the employees details in the system.
4. The employee's details are kept up-to-date.
