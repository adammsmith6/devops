# USE CASE: 5 Add Employee Details to the System

## CHARACTERISTIC INFORMATION

### Goal in Context

As an *HR advisor* I want *to add a new employee's details* so that *I can ensure the new employee is paid.*

### Scope

Company.

### Level

Primary task.

### Preconditions

We know the new employee's details.

### Success End Condition

The new employee is added to the system so they can be paid.

### Failed End Condition

The employee is not added to the system and does not get paid.

### Primary Actor

HR Advisor.

### Trigger

A request for a new employee's details to be added to the system is sent to HR.

## MAIN SUCCESS SCENARIO

1. Finance request a new employee be added to the system.
2. HR advisor captures details of the employee to be added to the system.
3. HR advisor adds the details of the employee to the system.
4. The employee gets paid.
